# Diario de desarrollo — Laberinto multijugador

## 1. Herramientas utilizadas

- Visual Studio Code
- JavaScript
- Node.js y Express
- Socket.IO
- Canvas
- Git y GitHub
- Claude Code y ChatGPT como herramientas de IA.

## 2. Idea del proyecto

Al principio quería crear un juego donde los jugadores recogieran monedas. Después decidí cambiar la idea por un laberinto multijugador.

El objetivo actual es conseguir 3 llaves y encontrar la salida antes que los demás jugadores. Habrá trampas, potenciadores y enemigos.

## 3. Decisiones técnicas

- Juego para navegador web.
- JavaScript para el cliente y el servidor.
- Canvas para dibujar el juego, en lugar de Phaser.
- Node.js y Express para el servidor.
- Socket.IO para la comunicación en tiempo real.

## 4. Preparación y problemas

Creé la carpeta del proyecto, inicié Git y lo conecté con GitHub. También preparé los archivos `DISENO.md`, `DIARIO.md` y `.gitignore`.

Durante la preparación tuve un problema con npm en PowerShell porque Windows bloqueaba la ejecución de scripts. Lo solucioné cambiando la política de ejecución para mi usuario.

También instalé Claude Code y configuré su acceso desde VS Code.

## 5. Uso de inteligencia artificial

He utilizado Claude Code para planificar y desarrollar el proyecto, y ChatGPT para entender conceptos, organizar las ideas y preparar instrucciones.

Decidí empezar de nuevo con la planificación porque quería entender mejor el proyecto antes de programar.
